> 病害预警场景里误报的代价是人工复核（便宜），漏检的代价是一整片作物（昂贵），所以要保召回；若是自动喷药，误报的代价反而更高。这类取舍能讲清楚，比报一个 mAP 数字更有说服力。

## 5. 口径说明（避免误读）

- 这是 **VOC 风格的单阈值 AP**（IoU=0.5，all-point 插值），
  不是 COCO 的 mAP@[.5:.95]，两者数值不能直接对比。
- 匹配是**贪心**的：同一图上同类别的检测按置信度从高到低，
  与尚未被占用的 GT 做匹配，IoU 达标即算 TP，一个 GT 只能被匹配一次。
- AP 用全部置信度的检测计算（`conf_thres` 设得很低以保留完整 PR 曲线），
  而 P/R/F1 是在工作点（`conf >= op_conf`）上统计的，两个口径分开看才对。
- 有 GT 但整类一个框都没检出的类别，AP 记 0 并计入分母，不会从 mAP 里消失。
